You are a senior staff-level software engineer and system architect. Your task is to design and implement a production-ready mobile application called **inMyCity**, a smart city explorer app for both tourists and residents.

---

## 🎯 PRODUCT GOAL

Build a scalable, real-world mobile app that answers:

1. What can I do near me right now?
2. What are the best places to visit in this city?
3. What events or deals are happening nearby?

The system must prioritize:

* Fast performance (<200ms API latency)
* High usability
* Clean architecture
* Scalability to 1M+ users

---

## 📱 CORE FEATURES (STRICT MVP SCOPE)

### 1. Smart Explore (Primary)

* Detect user location (GPS)
* Show nearby places:

  * Food & Cafes
  * Attractions
  * Essentials
  * Nightlife
* Map + list view toggle
* Filters:

  * Distance
  * Rating
  * Open now
* Place detail page:

  * Images, timings, contact info
  * Distance and ETA
* Save/bookmark places

---

### 2. Tourist Mode

* Predefined itineraries:

  * 1-day plan
  * 3-day plan
* Multi-stop route optimization
* Show tips (best time, cost, notes)

---

### 3. Events Module

* Event discovery feed
* Filters: date, category
* Event detail page
* Redirect to external booking (no payment system in MVP)

---

### 4. Deals Module

* Nearby deals based on location
* Deal detail page:

  * Discount info
  * Expiry countdown
* Redemption via QR or code
* Geo-triggered notifications

---

### 5. Save & Plan

* Save places
* Create collections
* Plan trips with multiple saved places

---

## 🧱 TECH STACK (MANDATORY)

### Frontend (Mobile)

* React Native with TypeScript
* State management: Zustand or Redux Toolkit
* Data fetching: React Query
* Maps: Google Maps SDK
* Notifications: Firebase Cloud Messaging

---

### Backend

* Use Node.js (Fastify) OR Java (Spring Boot)
* Follow clean architecture or modular monolith (do NOT over-engineer microservices initially)

---

### Database

* PostgreSQL with PostGIS (for geo queries)
* Redis (for caching)

---

### Search

* Elasticsearch (for geo + text search)

---

### Infra

* AWS (or equivalent):

  * API Gateway
  * Container service (ECS/EKS)
  * S3 (image storage)
  * CDN (CloudFront)

---
